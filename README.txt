TZIA Piano · App

La app es un PWA: piano interactivo, 12 tonalidades, relativas, paralelas,
escalas, acordes y audio Web Audio.

Para instalarla como una app real en iPhone:
1. Sube esta carpeta a un alojamiento HTTPS.
2. Abre index.html desde Safari.
3. Compartir → Añadir a pantalla de inicio.

Importante: iOS no permite instalar un PWA desde un archivo local sandbox directamente.
El HTML sí funciona como página web, pero la instalación "como app" requiere HTTPS.
